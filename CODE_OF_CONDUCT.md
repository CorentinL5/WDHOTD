# Community guidelines

Be respectful, patient and specific. Critique code and ideas, not people. Welcome newcomers and keep discussions connected to the project. Harassment, threats, discriminatory abuse, doxxing, spam and repeated disruption are not welcome.

Do not post personal information, credentials or private security reports. Follow [SECURITY.md](SECURITY.md) for sensitive issues.

The repository owner moderates participation and may edit or remove disruptive content, close discussions or restrict access. For a sensitive conduct concern, contact the owner privately through an available GitHub channel; if none is available, request a private contact without naming people or exposing details publicly.
